# Pudding Studio

以 Svelte 5、Vite、Tailwind CSS 4 與 shadcn-svelte 製作的圖片局部 Q 彈動畫編輯器。預設繁體中文，右上角可切換英文。

## 啟動

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

```sh
npm run check
npm run build
npm run preview
```

推送至 `master` 後，GitHub Actions 會建置並部署至 [GitHub Pages](https://amemizuki.github.io/pudding-studio/)。

## 使用方式

1. 上傳或拖入 PNG、JPEG、WebP；也能直接使用內建的程式繪製布丁示範圖。
2. 用圓形的「增強畫筆」塗刷想晃動的部位：游標圓圈蓋到的範圍就是塗到的範圍，不會多也不會少。一筆之內來回塗不會越疊越強，每一筆最多增加一次「筆刷力度」（預設 100%）；「減弱畫筆」同理，力度 100% 一筆即可清除。在空白處下筆會建立新區域（最多 8 個），第一筆的中心就是該區域的錨點；從既有區域上下筆則會加強該區域。
3. 每個區域以各自的飽和色塊顯示，顏色越深代表塗刷越強；目前選取的區域另有實線外框。游標讀值顯示該處塗刷量。
4. 晃動權重以筆刷範圍為主：錨點（白框實心圓點）處最強，往外漸弱，筆刷內的顏色深淺即代表權重。實際變形會從筆刷邊緣向外柔和延伸（至少為幅度的 2 倍），讓物體輪廓跟著動，不會被釘在原地。切到「移動／錨點」後拖曳錨點即可改變權重分布。右側「錨點與範圍」可調整起始角度（0° 向右、90° 向下）、晃動範圍（20–300%，100% 剛好延伸到最遠的筆刷）與完整強度範圍（0–90%，越高越均勻、越低越從錨點漸弱）。
5. 每個區域可獨立套用布丁 Q 彈（輕點後衰減的多次回彈）、左右搖擺（錨點左右滑動、遠處跟隨）、彈力跳跳（平順上下、底部壓扁頂部拉長）、水波抖動（兩圈向外波紋，限制位移不交疊），並調整晃動強度（0–60 px）、速度、彈性及邊緣柔化。「移動／錨點」可拖曳填刷範圍；「區域位置與尺寸」可用鍵盤輸入名稱、位置和大小。眼睛按鈕可停用個別區域。
6. 即時播放、暫停、拖曳時間軸、比較原圖或隱藏區域顏色與錨點。塗刷或拖曳期間預覽顯示未變形的原始座標。Space 播放／暫停；Ctrl/⌘+Z 復原；Ctrl/⌘+Shift+Z 重做；Delete 刪除所選區域；Esc 取消尚未完成的填刷或拖曳。
7. 選擇 WebM 或 GIF、2–6 秒、15/24/30 fps、輸出尺寸後匯出。處理期間可取消；匯出不包含區域顏色、筆刷游標或錨點。

介面採用方角面板、方形播放鍵與滑桿控制點；唯一的圓形是代表筆刷範圍的游標。標題 28–36px、操作文字 16px、輔助文字至少 14px；手機維持字級並改為單欄，預覽與匯出設定優先顯示。字型採本機中文字型與自託管 Nunito Sans 拉丁字元。

## 處理與輸出

- 所有圖片、選區與編碼都在瀏覽器內處理；沒有後端、帳號或上傳請求。字型和套件由本站提供。僅語言偏好會存於 localStorage。
- 需支援 WebGL 的瀏覽器；建議最新版 Chrome 或 Edge。系統開啟減少動態效果時，預覽預設暫停；使用者仍可主動播放。
- 來源檔最大 20 MB、邊長上限 8192 px；預覽長邊限制 1440 px。GPU 紋理限制較低時會等比例縮小。
- WebM 使用瀏覽器 MediaRecorder（優先 VP9，再 VP8），約需動畫長度的時間錄製。GIF 使用 gifenc 在 Web Worker 中逐格編碼，無額外伺服器。
- 尺寸選項以長邊 480/720/1080 px 等比例輸出；GIF 長邊上限 720 px。來源透明處在兩種輸出中都會填入暖白色。
- GIF 設為無限循環。每個區域的頻率會四捨五入成動畫長度內的整數循環，預覽與匯出首尾完全吻合；離錨點越遠相位越晚，形成向外傳遞。預覽速度只影響預覽，不改變匯出。
- 每區域使用長邊最多 512 格的 0–255 強度遮罩（需支援 4096 px 紋理的 GPU），保留圖片比例與未填刷區域；不是背景修補或去背工具。筆刷大小、幅度與距離以 960px 參考寬度等比例計算。區域顏色跟隨變形後的內容移動。
- 更換圖片會清除區域與復原記錄。此版本不會跨重新整理保存專案。
